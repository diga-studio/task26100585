# MapLens

地图视窗裁剪库（Go）。从本地 GeoJSON 文件装载行政区域集合，按经纬度视窗
裁剪，直接在内存中计算并把结果返回调用方。纯标准库实现，无外部依赖。

## 能力

- `LoadFile(path)`：装载 GeoJSON FeatureCollection。每个区域取 `id`
  （或 `properties.id`）作为唯一标识；几何仅支持 `Polygon` / `MultiPolygon`。
- `Clip(west, south, east, north)`：返回各区域与视窗的几何交集，仅保留
  正面积部分；同一区域的全部连通分量归在一个结果中并保留原标识。

## 用法

```go
lens, err := maplens.LoadFile("regions.geojson")
if err != nil { /* ... */ }

// 普通视窗：西 < 东
feats := lens.Clip(100, 20, 130, 50)

// 跨日界线视窗：西 > 东（西 170、东 -170 表示宽 20 度）
feats = lens.Clip(170, -10, -170, 10)

// 全经度视窗
feats = lens.Clip(-180, -85, 180, 85)

for _, f := range feats {
    switch g := f.Geometry.(type) {
    case maplens.Polygon:      // 单面：g[0] 为外环，g[1:] 为洞
    case maplens.MultiPolygon: // 多面
    }
}
```

## 语义约定

- 平面经纬度计算（直线段，非球面测地线）。输入经度 [-180,180]、纬度 [-85,85]；
  相邻顶点取经度差绝对值小于 180 的唯一走向展开。
- 输入环方向与起点任意，内部统一规范为外环逆时针、洞顺时针；输出同此约定，环闭合。
- 视窗：`south < north`；`west < east` 普通视窗，`west > east` 跨日界线，
  `west=-180, east=180` 覆盖全部经度。
- 结果经度保持在 [-180,180]；跨日界线的面在该经线处分成两侧，不输出横跨地图的长边。
- 仅接触视窗边或角的区域不返回；视窗完全落在洞内时该区域不返回。
- 裁剪可能产生多个不连通分量（输出 `MultiPolygon`），洞可能被切开成为外边界缺口；
  结果保留真实连通关系与洞。
- 每次 `Clip` 都针对原始几何，互不影响；`Lens` 可并发只读使用。

## 实现要点

- 每个 Polygon 先展开到连续经度区间（宽度 < 180），再按 360 度整数倍平移
  与视窗区间求交，因此普通、跨线、全经度视窗走同一条裁剪路径。
- 矩形裁剪：多边形环边裁剪进矩形 + 矩形边界落在多边形内的部分合成有向边集，
  经共线反向边抵消后做半平面面追踪，恢复连通分量与洞的归属。
- 结果在 ±180 经线处再次切分并平移回 [-180,180]。
